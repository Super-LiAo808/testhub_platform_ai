### 修复
- 页面扫描进度卡在 15%：根因为 Windows 下 `multiprocessing.Queue` 回传大数据与 `join` 死锁；改为文件落盘 + 轻量信号，并在 `browser.close` 卡住时回收已抽取结果。
- 扫描超时与失败场景：加长超时；失败时尽量写入已抽取元素；去掉易拖死的 `networkidle` 等待。
- 前后端扫描协议不一致（同步结果 vs 异步 `job_id`）导致前端误报失败。

### 重构 / 体验 / 文档
